# Done Means Checked

A Claude skill that stops "it's done" when it isn't.

**The promise:** Claude lists every request, checks each one on the live result at phone and desktop size, and reports how many are done, what's open, and what it didn't check.

## Who it's for

Anyone who's sent AI-made work to a client or a boss and then found the mistakes after they did. Coaches, agency owners, creators, and people using AI at their job.

I'm Ekai Stone. I wrote this rule the day an agent told me a job was finished and it wasn't. Every agent I run follows it now.

## What's inside

| File | What it is |
|---|---|
| `skill/done-means-checked/SKILL.md` | The skill. Claude loads it before it says done, finished, fixed or live |
| `INSTALL.md` | How to add it in Claude.ai, Claude Cowork and Claude Code, plus a paste-in version for ChatGPT |

## How to use it

1. Install the skill with `INSTALL.md`.
2. Pick one real job you think is finished.
3. Paste every request for that job and say: `Use the done-means-checked skill. List every ask as its own row before you check anything.`
4. Give it the live link, or one phone screenshot and one desktop screenshot of each page.
5. Read the 3-part report: X of Y done, what's open, what wasn't checked.
6. Send the open rows back. It fixes them one at a time and checks each one again.

## The rule in 3 lines

1. A list first. One row per ask.
2. A row is done only when it was seen on the live result, at phone size and desktop size.
3. Every report says X of Y done, what's open, and what wasn't checked.

## What it doesn't do

- The AI that did the work is still the one checking it. A fresh reviewer catches more.
- It can only check what it can see. Pages behind a login need your screenshots.
- It works one job and one chat at a time. It doesn't remember your business in a new chat.
- It finds what's open. It doesn't judge if the work is good.
